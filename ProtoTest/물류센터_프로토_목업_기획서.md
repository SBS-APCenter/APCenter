# 물류센터 1지역 프로토타입 — 목업 제작 기획서

> 이 문서는 목업(테스트용 프로토) 제작 프롬프트에 그대로 넘기기 위한 기획 정리본입니다.
> 목적: 기획 회의에서 나온 규칙을 눈으로 보고 직접 조작해 보며 빠르게 이해하기 위한 **간이 목업**.
> 완성도·연출·밸런스보다 **규칙과 흐름이 맞게 동작하는지** 확인하는 것이 우선입니다.

---

## 1. 게임 개요

- 장르: 물류센터 경영 / 운영 시뮬레이션 (모바일 느낌의 쿼터뷰 맵)
- 핵심 루프: **계약 → 하차 → 분류(적재) → 검수 → 주문 확인 → 운반 → 포장 → 상차 → 출발(정산)**
- 이번 범위: **1지역** 프로토타입, **총 11레벨**까지 (프로토 구현 시점 = 11레벨)
- 11레벨 시점에서 게임의 핵심 행동을 처음으로 모두 경험할 수 있음
  - 화물 옮겨보기 / 알바 고용 / 코스튬 / 구역확장(반품 구역)
  - ※ 알바 고용은 이번 목업에 포함 (4-5, 5-1장 참고), 코스튬은 범위 밖 (7장 참고)

## 2. 맵 구성 규칙

- 모든 구역은 **같은 크기의 네모난 칸(블록)** 으로 구성된다.
- 레벨이 오르면 **새로운 칸이 기존 건물 옆에 붙으면서** 물류센터가 커진다.
- 플레이어가 아무 곳에나 자유롭게 시설을 놓는 방식이 **아니다**.
  - 시설이 생기는 **자리는 미리 정해져** 있고, 정해진 레벨이 되면 그 자리가 열린다.

### 2-1. 구역 색상 / 종류

| 색상 | 구역 | 비고 |
|---|---|---|
| 주황(살구) | 사무실 | 좌상단, 계약 진행 |
| 노랑 | 적재구역 | 중앙 + 우측 하단, 선반 배치 |
| 파랑 | 하차구역 | 트럭이 들어와 택배를 내려놓는 곳 |
| 초록 | 상차(출고)구역 | 포장대 + 상차 트럭 |
| 갈색(빨강) | 반품구역 | 우하단, 10레벨에 추가 |

> ✅ 확정: 파랑 = 하차, 초록 = **상차(출고)**.

### 2-2. 맵 단계별 구성

- **게임 시작 시: 총 7칸**
  - 초기 활성 구역: **사무실, 상차(2칸), 적재(2칸), 하차(2칸)**
  - 나머지 칸은 잠긴/빈 칸 (회색으로 표시)
  - 초기 배치 (3×3 격자, 첨부 이미지 1 기준 / 흰 칸 = 적재):

    | | 열1 | 열2 | 열3 |
    |---|---|---|---|
    | 행1 | 사무실 | 상차 | (빈칸) |
    | 행2 | 하차 | 적재 | 상차 |
    | 행3 | (빈칸) | 하차 | 적재 |

- **11레벨 최종 맵 (1지역 프로토 최종)**: 총 10칸 (첨부 이미지 2 기준, 3레벨 좌측 하차 / 7레벨 우측 상차 / 10레벨 우하단 반품이 추가된 형태)
  - 사무실 1 / 적재 2 / 하차 3(파랑) / 상차 3(초록) / 반품 1

### 2-3. 레벨별 구역 해금

| 레벨 | 추가되는 구역 | 위치 |
|---|---|---|
| 3 | 하차구역 +1 | 좌측 |
| 7 | **상차구역** +1 | 우측 |
| 10 | 반품구역 +1 | 우하단 |

### 2-4. 해금 방식 (발판 + 게이지)

1. 해당 레벨 달성 시, 열릴 자리에 **해금 발판**이 생긴다.
2. 플레이어 캐릭터가 발판 위에 올라가면 **버거플리즈 방식**으로 **돈이 서서히 빠져나가며 게이지가 찬다.**
3. 게이지가 가득 차면 구역이 **해금**되고 칸이 맵에 붙는다.
4. 돈이 부족하거나 발판에서 내려오면 진행이 멈춘다(채운 게이지는 유지).
5. 해금 비용은 임시값으로 둔다 (밸런스는 추후).

## 3. 튜토리얼 (게임 시작)

1. 게임은 **사무실 안(계약 화면)** 에서 시작한다. 별도의 이동 유도는 없다.
2. 사무실에서 **계약**을 진행한다.
3. 처음에는 **두 개의 회사**와 계약한다.
   - 회사 A: **신발** 회사 → 물품 2종: 신발 / 슬리퍼 (2번째 물품은 임시)
   - 회사 B: **라면** 회사 → 물품 2종: 라면 / 과자 (2번째 물품은 임시)
   - 계약 탭에는 회사 패널 3개가 뜬다.
   - **지정된 2개 회사(신발/라면)만 계약 가능**하다. 나머지 1개 패널은 **어둡게 처리**하고 **계약 버튼을 막아** 반강제로 진행시킨다. 튜토리얼 중에는 리롤하지 않는다.
   - 화면에 **"회사와 계약을 체결하세요"** 안내 텍스트를 표시한다. (문구는 임시)
   - **튜토리얼은 계약까지만**이다. 2개 회사와 계약을 마치면 튜토리얼이 끝나며, 이후 튜토리얼은 없다. 종료 후 3번째 패널 잠금이 풀리고 리롤이 가능해진다.
4. 계약이 완료되면 계약한 회사의 물품이 입고되기 시작한다.
5. 계약·알바 고용은 모두 **사무실**에서 진행한다. 화면 구성은 5-1장 참고.

## 4. 핵심 플레이 흐름

### 4-1. 하차 (입고)

- **하차구역**(하차도크)으로 트럭이 들어온다. 하차구역 1칸당 트럭 1대.
- 트럭은 계약한 물품을 **랜덤하게 총 10개(택배 박스 단위)** 싣고 온다. (계약한 회사 물품이 섞여 있음)
- 플레이어/알바는 택배를 트럭에서 **하차도크에 내린다(하차)**, 그 뒤 **분류**로 적재구역 선반에 옮긴다.
- **회차 규칙**
  - 트럭 도착 후 **일정 시간(임시 60초)** 이 지나면 **내리지 못한 택배를 그대로 싣고 회차**한다.
  - 택배를 **전부 내렸으면 즉시 회차**한다.
  - 회차 후 **15초 뒤** 다음 트럭이 도착한다. (재방문 주기 15초)

### 4-2. 적재

- 적재구역에는 **선반**이 있다.
  - 선반 1개당 **10개** 적재 가능 (초기)
  - 구역 1칸당 선반 **4개**, 적재 구역 **2칸** → 총 **선반 8개** (초기 최대 80개)
- **선반의 물품 종류는 회사와 계약할 때 정해진다.** 계약하면 빈 선반 2개에 그 회사의 물품 2종 **라벨**이 각각 붙는다. (회사 1곳 = 물품 2종 = 선반 2개)
  - 선반이 **비어도 라벨(물품)은 유지**된다.
  - **계약을 해지하면 라벨이 없어지고** 선반은 다시 비어 있는 상태가 된다. (선반에 남은 택배 처리는 10장 참고)
- 라벨과 맞지 않는 물품은 그 선반에 넣을 수 없다. (분류 시 알맞은 선반에만 적재)
- **최대 계약 가능 회사 수 = 선반 수 ÷ 2 = 4개** (빈 선반이 2개 미만이면 계약 불가)
- 선반 용량은 레벨업으로 **10 → 20개**로 확장된다. 레벨당 **선반 2개씩** (4-6장 레벨 보상 참고). 전부 확장되면 최대 160개.

### 4-2-1. 작업 정의 (하차 / 분류 / 검수 / 포장 / 운반)

| 작업 | 내용 |
|---|---|
| 하차 | 트럭의 택배를 **하차도크에 내려놓는다** |
| 분류 | 하차도크의 택배(물품)를 **알맞은 선반**에 갖다 놓는다 |
| 검수 | 선반에 있는 택배를 **해당 선반 앞에서 검수해서 체크**한다. **검수하지 않은 택배는 포장할 수 없다** |
| 운반 | **주문서의 물품을 들고 포장대로 이동해 내려놓는다** |
| 포장 | **포장대 앞에서** 포장대의 물품을 **주문서에 맞게 한 택배로 묶는다** |
| 상차 | 포장대의 **포장된 택배를 상차도크의 트럭에 싣는다** |

- 플레이어와 알바 모두 이 작업을 수행할 수 있다. (알바는 배치된 구역의 작업을 수행, 4-5장)
- 알바는 **지능** 수치에 따라 검수/포장 등 작업 속도가 빨라진다. (4-5장)
- 선반의 택배는 **검수 전 / 검수 완료** 상태를 가진다. 선반 UI에 검수 완료 수량 표시(예: 신발 6/10, 검수 4).

### 4-3. 주문 (출고 요청)

- **10초마다 주문서 1건**이 들어온다.
- 주문서에는 **물품 종류 + 개수**가 적혀 있다. (예: 신발 2개, 라면 3개)
- 주문서에 들어가는 물품은 **계약한 회사의 물품**이며, 물품마다 **주문 빈도 등급(1~5)** 으로 포함 확률이 정해진다.

| 주문 빈도 | 5 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|
| 포함 확률 | 모든 주문서(1/1) | 2건에 1번(1/2) | 3건에 1번(1/3) | 4건에 1번(1/4) | 5건에 1번(1/5) |

- 포함된 물품의 개수는 임시로 1~3개. 주문서에 한 종류도 포함되지 않으면 계약 물품 중 하나를 임의로 넣는다. (임시)
- 대기 중인 주문서가 쌓일 수 있는 최대 수는 임시 10건. 가득 차면 새 주문은 생성하지 않는다.

### 4-4. 포장 / 상차 (출고)

1. **운반**: 주문서에 적힌 물품을 **개수만큼** 적재구역 선반에서 꺼내 들고 포장대로 이동해 내려놓는다. (**검수 완료된 택배만** 가능)
2. **포장**: 포장대 앞에서 물품을 주문서에 맞게 **한 택배로 묶는다**. (**주문서 1건 = 택배 1개**)
3. **상차**: 포장된 택배를 **상차도크의 상차 트럭**에 싣는다.
4. 상차 트럭은 **최대 10개**의 택배를 실을 수 있다.
5. 택배를 **하나라도 실으면 [출발] 버튼이 활성화**된다.
6. [출발]을 누르면 **그때 트럭이 출발**한다. (자동 출발 없음)
7. 출발 시 싣고 간 **택배(주문)마다 금액 / 경험치**가 지급된다. 금액 = 택배에 든 **물품 가격의 합**, 경험치 = 택배 1개당 고정값. (임시값은 6장)

### 4-5. 알바 (고용 / 배치 / 스트레스)

**스탯** (각 최대 5)

| 스탯 | 영향 |
|---|---|
| 힘 | **힘 수치만큼** 택배를 들 수 있음 (힘 3 = 3개) |
| 민첩 | 이동속도 (임시: 2.0 + 0.4 × 민첩) |
| 지능 | 검수/포장 등 작업속도 (임시: 작업 1회 3초 − 0.4 × 지능, 최소 1초) |

- 수치는 모두 임의값이며 설정값으로 분리한다.

**고용**
- 사무실에서 후보 알바 3명이 표시되고, [고용] 버튼으로 고용한다.
- 시급은 스탯이 좋을수록 높게 임시 설정 (임시: 스탯 합 × 10). 인게임 하루(임시 5분)가 지날 때마다 시급 × 8을 인건비로 지급 (임시).
- 후보는 **인게임 하루가 지나면 자동 리롤**되고, 우측 상단 [리롤] 버튼으로 수동 리롤도 가능하다.

**배치**
- 구역: **하차 / 분류 / 검수 / 운반 / 포장 / 상차** (+ 대기칸) — 4-2-1장 작업과 1:1
- **구역별 배치 인원 제한: 3명** (임시). 대기칸은 제한 없음.
- 고용 직후 알바는 **대기칸**에 들어간다.
- 맵에서도 대기 인원은 **사무실 앞 작은 대기구역**에 서로 **겹치지 않게** 서 있는다.
- 구역에 배치된 알바는 해당 구역 작업을 자동으로 수행한다. (검수 = 선반 앞, 포장 = 포장대 앞 등 작업 위치는 4-2-1장 참고)

**스트레스**
- 일하는 동안 **꾸준히 증가**한다. (임시: 초당 +1)
- **100**이 되면 잠시 일을 쉰다. (임시: 10초 휴식 후 스트레스 0)

**해고**
- 알바 상태 목록에서 [해고] 버튼으로 해고한다.

### 4-6. 플레이어 능력 / 레벨 보상

**플레이어 기본 능력**
- 한 번에 들 수 있는 택배: **기본 4개**
- 이동속도, 작업속도: 기본값은 임시 (설정값으로 분리)
- 세 능력(들 수 있는 개수 / 이동속도 / 작업속도)은 사무실 UI의 **[플레이어 업그레이드]** 탭에서 돈으로 올린다. (5-1장)

**레벨 보상** (2레벨~11레벨, 구역 해금은 2-3장 참고)

| 레벨 | 보상 |
|---|---|
| 2 | 선반 2개(1·2번) 용량 10 → 20 |
| 4 | 선반 2개(3·4번) 용량 10 → 20 |
| 5 | 선반 2개(5·6번) 용량 10 → 20 |
| 6 | 선반 2개(7·8번) 용량 10 → 20 (마지막) |
| 8 | **하차구역 칸마다 입고 차량 +1대** |
| 9 | **주문량 증가** (임시: 주문서 물품 개수 +50%) |
| 11 | 다음 지역 해금 (**표시만**, 지역 구현 없음) |

- 3 / 7 / 10레벨은 구역 해금(2-3장).
- 선반 8개가 모두 20칸이 되면 총 적재량은 최대 160개.

### 4-7. 작업 발판 (상호작용 방식)

- 작업은 **버튼 없이, 작업 발판 위에 서 있으면 자동으로 진행**된다.
- 작업 발판은 **점선 테두리의 원형 발판**으로 표시한다. (해금 발판(2-4장)과 다른 모양/색으로 구분)
- 플레이어와 알바 모두 같은 규칙이다. 알바는 배치된 구역의 작업 발판으로 이동해 서서 작업한다. 점유 중이면 빈 발판을 쓴다.
- 작업 1회 시간은 지능(플레이어는 작업속도 업그레이드)에 따른다. 한 번에 들 수 있는 수는 힘(플레이어는 개수 업그레이드)에 따른다.

| 작업 | 발판 위치 | 동작 (임시) |
|---|---|---|
| 하차 | 하차 트럭 앞 | 트럭의 택배를 하차도크에 내린다 |
| 분류 | 하차도크 발판 → 선반 앞 발판 | 도크에서 택배를 들고(최대 수량), 선반 발판에서 **라벨이 맞는 선반**에 넣는다 |
| 검수 | 선반 앞 발판 | 해당 선반의 미검수 택배를 검수 완료로 바꾼다 |
| 운반 | 선반 앞 발판 → 포장대 발판 | 주문서 물품(검수 완료)을 꺼내 들고, 포장대에 내려놓는다 |
| 포장 | 포장대 앞 발판 | 포장대의 물품을 주문서에 맞게 택배 1개로 묶는다 |
| 상차 | 상차 트럭 앞 | 포장대의 완성 택배를 상차 트럭에 싣는다 |

- 발판 개수·위치는 씬에서 배치 (임시: 선반마다 1개, 포장대·트럭 앞 각 1~3개).
- 발판은 프리팹으로 만들어 씬에 미리 배치한다. (5-7장)

## 5. 목업 화면 구성 (제안)

- **메인 맵 뷰**: 쿼터뷰/탑뷰로 칸 구조를 보여주고, 구역별 색으로 구분
- **상단 HUD**: 현재 레벨, 보유 돈(, 경험치 바)
- **주문서 패널**: 들어온 주문 목록 (물품/개수/진행 여부)
- **캐릭터**: 키보드(방향키/WASD) 또는 다이나믹 조이스틱으로 이동 (5-4장), 작업 발판 위에 서 있으면 작업 자동 수행 (4-7장)
- **설정 버튼**: 화면 한쪽에 설정 버튼 1개. 누르면 설정 창이 열리고 **[게임 종료]** 버튼이 있다. (5-5장)
- **하차 트럭 / 상차 트럭**: 적재 수량 표시(예: 7/10), 상차 트럭에는 [출발] 버튼
- **선반**: 선반별 종류 및 수량 표시(예: 신발 6/10)
- **해금 발판**: 발판 위 게이지와 필요 금액 표시
- **디버그 도구(목업용)**: 레벨 올리기(레벨업) / 돈 추가 / 트럭 즉시 호출 / 주문 즉시 생성 / **게임 초기화** 버튼
- **디버그 돈 창(작은 창)**: 
  - 보유 돈을 **직접 입력해서 수정**할 수 있다. (입력 후 적용)
  - 정해진 금액만큼 **더하기 / 빼기 버튼**을 둔다. (예: ±1,000 / ±10,000 / ±100,000, 금액은 설정값)

### 5-1. 사무실 UI (계약 / 알바 관리)

사무실에 들어가면 **클립보드 형태의 UI**가 열리고, **UI가 열려 있는 동안 게임 시간이 정지**한다. (트럭 도착, 주문 생성, 알바 작업/스트레스, 리롤 타이머 모두 정지. 닫으면 재개) 클립보드 우측에 **인덱스 포스트잇 탭**이 붙어 있고, **[계약]** / **[알바관리]** / **[플레이어 업그레이드]** 탭을 눌러 화면을 전환한다.

**① 계약 탭**
- 회사 패널 **3개**가 **가로로 긴 패널을 세로로 나열**(≡ 모양)한다.
- 패널 내용: 회사명, 다루는 물품, **물품 가격**, **주문 빈도(1~5)**, **계약금**. 가장 오른쪽에 **[계약] 버튼**.
- [계약]을 누르면 **계약금을 지불**하고 계약된다. (돈 부족 시 비활성) 계약하면 빈 선반 2개에 물품 2종 라벨이 붙는다. (4-2장)
- 패널에는 회사의 **물품 2종**이 각각 가격 / 주문 빈도와 함께 표시된다. 계약금은 회사 단위.
- 패널 아래에 **계약 중인 회사 목록**(최대 4개)을 둔다. 각 항목에 회사명 / 물품 2종 / 배정된 선반 2개 / **[해지]** 버튼. 해지하면 선반 라벨이 사라진다. 리롤은 위쪽 3패널만 바꾼다. (임시 구성)
- 알바와 같이 **[리롤]** 가능 (인게임 하루 경과 시 자동 리롤 + 수동 버튼). 리롤하면 새 회사 **3개 패널**이 나온다.
- **최대 계약 가능 회사 수는 선반 수에 따른다. (선반 8개 ÷ 회사당 2개 = 4개)**

**② 알바관리 탭** (위에서 아래로 스크롤)
1. **고용 영역**
   - 알바 패널 **3개**를 가로 패널로 세로 나열(≡).
   - 패널 왼쪽: 증명사진 + 그 아래 이름 / 가운데: 힘·민첩·지능 3줄(≡)과 수치 / 오른쪽: 시급 + 그 아래 [고용] 버튼.
   - 우측 상단: [리롤] 버튼, 그 위(또는 아래)에 **자동 새로고침까지 남은 시간(nn분 nn초)** 표시.
2. **배치 영역**
   - 구역 칸: 하차 / 분류 / 검수 / 운반 / 포장 / 상차 (+ 대기칸). 구역별 최대 3명.
   - 고용한 알바를 **작은 이름표**로 만들어 **드래그 앤 드롭**으로 칸에 배치한다.
   - 시작 시 모든 이름표는 **대기칸**에 둔다.
3. **알바 상태 영역**
   - 고용한 알바별 스탯, 스트레스 수치, 시급 등을 표시.
   - 우측에 [해고] 버튼.

**③ 플레이어 업그레이드 탭**
- 업그레이드 항목 3개: **들 수 있는 택배 개수**(기본 4) / **이동속도** / **작업속도**
- 항목마다 현재 수치, 다음 단계 수치, 비용, [업그레이드] 버튼을 표시한다. 돈이 부족하면 버튼 비활성.
- **최대 5단계**, 아래 수치는 임시 (설정값으로 분리)

| 단계 | 들 수 있는 택배 (비용) | 이동속도 (비용) | 작업 1회 시간 (비용) |
|---|---|---|---|
| 기본 | 4개 | 4.0 | 3.0초 |
| 1 | 5개 (500) | 4.4 (300) | 2.7초 (300) |
| 2 | 6개 (1,000) | 4.8 (600) | 2.4초 (600) |
| 3 | 7개 (2,000) | 5.2 (1,200) | 2.1초 (1,200) |
| 4 | 8개 (4,000) | 5.6 (2,400) | 1.8초 (2,400) |
| 5 | 10개 (8,000) | 6.0 (4,800) | 1.5초 (4,800) |

- **쿼터뷰** (고정 각도 탑다운 3D). 플레이어가 각도를 돌리지는 않는다.
- **캐릭터 추적**: 캐릭터가 이동하는 동안 카메라는 캐릭터에 **고정되어 따라다닌다**.
- **자유 시점**: 캐릭터가 **가만히 있을 때** 화면을 **드래그해서 다른 곳을 볼 수 있다**.

  - 캐릭터가 다시 움직이면 카메라는 캐릭터로 복귀해 추적을 재개한다.
  - 사무실 UI가 열려 있는 동안에는 드래그 비활성 (UI와 입력 충돌 방지).

### 5-4. 조작 (PC / 모바일)

- **키보드**: 방향키 / WASD 이동.
- **다이나믹 조이스틱** (마우스 클릭-드래그 / 터치-드래그):
  - 조이스틱 UI는 따로 띄우지 않는다. **누른 위치에 반투명 원형 표시만** 나타나 기준점을 알려준다.
  - 누른 위치를 기준으로 드래그한 **방향·거리**로 이동 방향/속도를 정한다.
  - **짧게 터치/클릭한 경우**는 조이스틱으로 반응하지 않고 **일반 클릭/터치**(UI 버튼, 상호작용)로 처리한다. 일정 시간(임시 0.15초) 이상 누르거나 일정 거리(임시 10px) 이상 드래그해야 조이스틱이 시작된다.
  - 손을 떼면 이동 정지, 원형 표시 사라짐.
  - UI(사무실 클립보드, 디버그 창, 설정 창) 위에서 시작한 입력은 조이스틱으로 쓰지 않는다.

### 5-5. 설정 / 게임 종료

- 화면 한쪽의 **설정 버튼** → 설정 창.
- 설정 창에 **[게임 종료]** 버튼. 누르면 게임을 종료한다. (실수 방지로 확인 창을 한 번 거친다. 에디터에서는 플레이 모드 종료)
- 설정 창에는 닫기 버튼도 둔다.

### 5-6. 캐릭터 / 애니메이션

| 역할 | 캐릭터 | 에셋 위치 |
|---|---|---|
| 플레이어 | **Basic** | `Assets/Resources/Charactor/Basic` (`basics_walk`, `basics_carry`) |
| 알바 | **Macaron** 또는 **rabbit** | `Assets/Resources/Charactor/Macaron`, `.../rabbit` (`*_walk`, `*_carry`) |

- 알바는 후보/고용 시 두 캐릭터 중 하나를 **랜덤 배정**한다. (임시)
- **idle 애니메이션이 없다.** `walk`와 `carry` 클립에서 **두 발이 땅에 닿은 프레임을 정지시켜 idle로 사용**한다.
  - 일반 상태 idle = walk 클립의 두 발 접지 프레임
  - 택배를 든 상태 idle = carry 클립의 두 발 접지 프레임
- 택배를 들고 있으면 carry, 아니면 walk 계열을 사용한다. 이동 중이면 클립 재생, 멈추면 접지 프레임으로 고정.

### 5-7. 제작 규칙 (Unity, 필수)

- **모든 오브젝트 / UI / 텍스트는 반드시 씬에 미리 배치**한다. **런타임 중 코드로 생성·배치(Instantiate, new GameObject, AddComponent로 UI 생성 등)하지 않는다.**
  - 항상 **하이어라키에서 눈으로 보고 수정**할 수 있어야 한다.
  - 코드는 씬에 있는 오브젝트를 **참조(SerializeField 연결)** 해서 켜고 끄거나 값만 바꾼다.
  - 트럭·선반·알바·택배처럼 여러 개가 필요한 것도 **씬에 필요한 수만큼 미리 배치**해 두고 활성/비활성으로 제어한다. (프리팹으로 만들어 씬에 배치, 5-3장)
  - 예: 알바 후보 패널 3개, 회사 패널 3개, 선반 8개, 하차 트럭 최대 칸 수 × 2대, 상차 트럭, 알바 이름표/캐릭터 풀 등.
- **폰트**: 한글이 깨지므로 모든 TMP 텍스트는 **`MALGUN SDF`**(`Assets/Font/MALGUN SDF.asset`, 맑은 고딕)를 사용한다. TMP 기본 폰트(Default)로 두지 않는다.

|---|---|

- 그래픽은 색 블록 + 아이콘/텍스트 수준이면 충분
- 데이터(회사, 물품, 주문, 레벨 해금 표)는 **코드 밖 설정값**으로 분리해 쉽게 수정 가능하게 한다
- 제작 환경은 미정 (폴더가 Unity 프로젝트라 Unity 기준이면 구역·선반·트럭 등을 프리팹/ScriptableObject 설정으로 분리, 웹 목업이면 단일 HTML)

- 11레벨 이후의 콘텐츠 (다음 지역 실제 구현 포함)

## 8. 용어 정리

| 용어 | 의미 |
|---|---|
| 하차 | 들어온 트럭에서 택배를 내리는 것 (입고) |
| 적재 | 내린 택배를 선반에 분류해서 넣는 것 |
| 분류 | 하차도크의 택배를 알맞은 선반에 갖다 놓는 작업 |
| 검수 | 선반 앞에서 택배를 확인·체크하는 작업 (검수 전 택배는 포장 불가) |
| 운반 | 주문서 물품을 들고 포장대로 이동해 내려놓는 작업 |
| 회차 | 하차 트럭이 (남은 택배를 싣고, 또는 전부 내린 뒤) 떠나는 것 |
| 작업 발판 | 점선 테두리 원형 발판. 위에 서 있으면 해당 작업이 자동 진행됨 |
| 라벨 | 계약 시 선반에 붙는 물품 표시. 비어도 유지, 계약 해지 시 제거 |
| 주문 빈도 | 물품이 주문서에 포함되는 정도 (1~5, 5 = 모든 주문서) |
| 상차 | 포장된 택배를 출고 트럭에 싣는 것 (출고) |
| 포장대 | 상차구역에 있는 포장 작업대 |
| 해금 발판 | 올라가면 돈이 빠지며 게이지가 차고, 가득 차면 구역이 열리는 발판 |
| 반품 구역 | 10레벨에 추가되는 구역 (우하단) |
| 힘 / 민첩 / 지능 | 알바 스탯. 들 수 있는 수량 / 이동속도 / 작업속도 (각 최대 5) |
| 스트레스 | 알바가 일하며 쌓이는 수치. 100이 되면 잠시 휴식 |
| 대기칸 | 구역에 배치되지 않은 알바가 머무는 칸 (사무실 앞 대기구역) |

## 9. 완료 기준 (체크리스트)

- [ ] 시작 시 7칸 맵에 사무실/하차/적재/상차가 보인다
- [ ] 사무실에서 신발·라면 두 회사와 계약할 수 있다
- [ ] 하차 트럭이 계약 물품을 랜덤 10개 싣고 온다
- [ ] 하차 트럭이 60초 후 또는 전부 하차 즉시 회차하고, 15초 뒤 다시 온다
- [ ] 택배를 하차도크에 내리고 분류에 맞게 선반에 적재할 수 있다 (선반당 10개, 총 8개)
- [ ] 선반 앞에서 검수할 수 있고, 검수하지 않은 택배는 포장할 수 없다
- [ ] 주문서 물품을 포장대로 운반 → 포장 → 상차 트럭에 실을 수 있다
- [ ] 상차 트럭은 최대 10개, 1개 이상이면 [출발] 활성화, 출발 시 택배당 돈/경험치가 지급된다
- [ ] 계약 탭도 리롤(자동/수동)되고 최대 4개 회사(선반 8개)까지 계약할 수 있다
- [ ] 구역별 알바 배치 인원이 3명으로 제한된다
- [ ] 디버그 창에 레벨업과 게임 초기화가 있다
- [ ] 사무실 클립보드 UI에서 [계약] / [알바관리] 탭을 오갈 수 있다
- [ ] 계약 탭에 회사 패널 3개가 세로로 나열되고 각 패널에서 계약할 수 있다
- [ ] 알바 후보 3명이 스탯·시급과 함께 표시되고 [고용]할 수 있다
- [ ] 리롤 버튼과 하루 경과 시 자동 리롤이 동작하고, 남은 시간(nn분 nn초)이 표시된다
- [ ] 이름표를 드래그 앤 드롭으로 하차/분류/검수/운반/포장/상차 칸에 배치할 수 있다
- [ ] 대기 알바가 사무실 앞 대기구역에 겹치지 않게 서 있다
- [ ] 알바 상태(스탯/스트레스/시급)가 보이고 [해고]할 수 있다
- [ ] 스트레스가 일하는 동안 증가하고 100이 되면 잠시 쉰다
- [ ] 모든 오브젝트/UI/텍스트가 씬 하이어라키에 배치되어 있고, 런타임 코드로 생성하지 않는다
- [ ] 모든 한글 텍스트가 `MALGUN SDF`로 깨지지 않고 표시된다
- [ ] 키보드와 다이나믹 조이스틱(누른 위치에 반투명 원만 표시)으로 이동할 수 있고, 짧은 터치는 일반 클릭으로 처리된다
- [ ] 플레이어는 Basic, 알바는 Macaron/rabbit 캐릭터를 쓰고, 멈추면 두 발 접지 프레임 idle(일반/택배 든 상태)이 나온다
- [ ] 설정 버튼 → 설정 창의 [게임 종료]로 게임을 끝낼 수 있다
- [ ] 작업 발판(점선 원형) 위에 서 있으면 하차/분류/검수/운반/포장/상차가 자동으로 진행된다
- [ ] 주문서가 10초마다 1건 들어오고, 물품은 주문 빈도 등급 확률로 포함된다
- [ ] 주문서 1건을 포장하면 택배 1개가 되고, 출발 시 물품 가격 합 / 경험치가 지급된다
- [ ] 계약 시 계약금이 빠지고 빈 선반 2개에 물품 라벨이 붙으며, 해지하면 라벨이 사라진다
- [ ] 게임이 사무실 계약 화면에서 시작하고, "회사와 계약을 체결하세요" 문구가 뜬다
- [ ] 지정된 2개 회사만 계약할 수 있고 나머지 1개는 어둡게 처리되어 계약이 막힌다 (리롤 없음)
- [ ] 2개 계약 완료 시 튜토리얼이 끝나고 잠금/리롤이 풀린다
- [ ] 사무실 UI가 열려 있는 동안 게임 시간이 정지한다
- [ ] 쿼터뷰이며, 캐릭터가 움직이면 카메라가 따라가고 멈춰 있을 때 드래그로 다른 곳을 볼 수 있다
- [ ] 트럭(AI_Truck)과 선반(AI_Shelf)이 프리팹으로 만들어져 맵에 배치된다
- [ ] 플레이어가 기본 4개를 들 수 있다
- [ ] [플레이어 업그레이드] 탭에서 들 수 있는 개수 / 이동속도 / 작업속도를 올릴 수 있다
- [ ] 2 / 4 / 5 / 6레벨에 선반이 2개씩 20칸으로 확장된다
- [ ] 8레벨에 하차구역 칸마다 입고 차량이 +1대, 9레벨에 주문량이 증가한다
- [ ] 11레벨 달성 시 다음 지역 해금 표시가 나온다
- [ ] 디버그 창에서 돈을 직접 입력해 수정하고, 정해진 금액만큼 더하기 / 빼기 할 수 있다
- [ ] 3레벨 좌측 하차 / 7레벨 우측 상차 / 10레벨 우하단 반품(구역만) 이 발판 + 게이지로 해금된다
- [ ] 11레벨 최종 맵이 첨부 이미지 2와 같은 구조가 된다
